# telegram-bot-frame

CLI scaffolding tool for Telegram bots.

This project is in MVP development. Stage 1 provides the initial TypeScript CLI package scaffold and a safe placeholder entry point.

## Planned usage

```sh
npx tbf init
npx telegram-bot-frame init
```

## Development

```sh
npm install
npm run build
node dist/index.js
node dist/index.js init
```
